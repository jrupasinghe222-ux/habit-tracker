# Habit Tracker

A full-stack web app for managing daily tasks and tracking progress.

**[View the live app](https://habit-tracker-nu-eosin.vercel.app/)**

## Features

- Google sign-in with persistent login.
- Add, edit, and delete tasks for a selected date.
- Mark tasks complete or undo completion.
- Browse and update earlier days without affecting other dates.
- View seven-day progress with daily completion ratios.
- Private task lists for each account.
- Responsive layout with keyboard-accessible controls.
